## Featured Projects

### 1. FocusFlow
An Android productivity application focused on helping users manage study sessions, subjects, schedules and productivity streaks.

**Technologies:** Kotlin, Android Studio

### 2. Weather Data Smoothing & Pattern Identification
A data analysis project using the Moving Average algorithm to smooth and identify patterns in Chennai weather data from 2020–2024.
